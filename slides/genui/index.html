Elige entre tus componentes: no inventa HTML Llega por partes (streaming) La persona ya la está usando

La persona no ve métricas: siente tres cosas

¿Ya está?LCP < 2,5 sLo principal aparece rápido.
¿Me hace caso?INP < 200 msCada clic responde al instante.
¿Se queda quieto?CLS < 0,1Nada salta mientras lees.

Con UI generativa sufren las tres a la vez: la página se construye mientras la usas.

Construir una casa mientras te dictan el plano

1dibujarReserva el espacioGuarda el lugar de cada parte antes de que llegue
2recibir por partesLee cada parte una sola vezNo vuelvas a leer todo desde el inicio
3reutilizar la pantallaReutiliza, no rehagasCambia solo lo que cambió

La IA es como un arquitecto que dicta el plano por partes; el navegador construye mientras escucha, y la persona ya está adentro usando la casa.

¿Cómo llega la respuesta?

          

            
 JSON completo
{"piezas":[{…},{…},
  {…},{…  ← ¿y si corto aquí?
Hay que esperar al final, o "arreglar" el JSON incompleto cada vez que llega una parte.
⚠ lento o frágil

            
 JSON por líneas
{"tipo":"plano",…}
{"tipo":"resumen",…}
{"tipo":"inmueble",…}
NDJSON (un JSON por línea): cada línea es un componente completo y se dibuja apenas llega.
✓ ideal para componentes

            
 HTML en streaming
<article><h2>Barranco…
<p>Encontré 6 departamentos…
El navegador lo dibuja solo. Bueno para texto; pero no controlas qué componentes se usan.
✓ para contenido

≈ 12 tarjetas reales
300 resultados

            

              
 Reutilizar filas
Unas pocas filas que cambian de contenido al hacer scroll, como la vitrina de una pastelería: mismos platos, distinto postre.

              
 content-visibility: auto
Lo más simple: el navegador no dibuja lo que no se ve. Con contain-intrinsic-size para que nada salte.

              
 View Transitions
Al reordenar, los mismos elementos se mueven con una animación.

 Worker
Ordenar, filtrar o sumar 300 departamentos lo hace tu código en un Web Worker (en paralelo, sin congelar la página). No se lo pidas otra vez al modelo.
