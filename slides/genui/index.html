// Core Web Vitals, en palabras de la persona

La persona no ve métricas: siente tres cosas

¿Ya está?LCP < 2,5 sLo principal aparece rápido.
¿Me hace caso?INP < 200 msCada clic responde al instante.
¿Se queda quieto?CLS < 0,1Nada salta mientras lees.

Con UI generativa sufren las tres a la vez: la página se construye mientras la usas.

// Regla 2 · el formato del dictado

          
¿Cómo llega la respuesta?

          

            
 JSON completo
{"piezas":[{…},{…},
  {…},{…  ← ¿y si corto aquí?
Hay que esperar el final o "reparar" el JSON a medias en cada trozo.
⚠ lento o frágil

            
 JSON por líneas
{"tipo":"plano",…}
{"tipo":"resumen",…}
{"tipo":"depa",…}
NDJSON: cada línea es una pieza completa. Se pinta apenas llega.
✓ ideal para piezas

            
 HTML en streaming
<article><h2>Barranco…
<p>Encontré 6 depas…
El navegador lo pinta solo. Bueno para texto; pierdes el control del catálogo.
✓ para contenido

          

        

        

      


      

        

          
// Regla 2 · por qué se congela

          
El error típico: releer todo con cada trozo

          

            Releer todo
            

            —caracteres leídos
            Leer una vez
            

            —caracteres leídos
          

          

            Trozos que llegan

            Frames de pantalla

          

          
El doble de respuesta = cuatro veces el trabajo. Y la pantalla no muestra más de ~60 cuadros por segundo: pinta una vez por frame.

// Regla 3 · listas largas

          
Listas largas, DOM corto

          

            
≈ 12 tarjetas reales
300 resultados

            

              
 Pool de nodos
Unas pocas tarjetas que cambian de contenido al hacer scroll, como la vitrina de una pastelería: mismos platos, distinto postre.

              
 content-visibility: auto
Lo simple: el navegador se salta pintar lo que no se ve. Con contain-intrinsic-size para no saltar.

              
 View Transitions
Al reordenar, los mismos nodos se mueven con animación.

// Regla 4 · gestión de estado

          
La IA dicta qué; tu código calcula cuánto

          

            
StreamCambios{"id":"bq-12","precio":2790}

            

            
📒 La libreta (store por id)bq-12 → S/ 2.790 · 64 m²
mf-03 → S/ 3.100 · 72 m²
ch-07 → S/ 2.400 · 58 m²
… 300 depas

            

            
Tarjeta bq-12 · se repinta
Tarjeta mf-03 · quieta
Gráfico · quieto

          

          
 Worker
Ordenar 300 depas, filtrar o sumar: tu código, fuera del hilo principal. No se lo pidas otra vez al modelo.
